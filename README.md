# موقع الاستعلام عن نتيجة الثانوية العامة

موقع بسيط (HTML/CSS/JS من غير أي سيرفر) للاستعلام عن نتيجة الثانوية
العامة برقم الجلوس أو بالاسم. مبني عشان يتنشر مجانًا على GitHub Pages.

## المحتويات

```
repo/
├── docs/              ← ده اللي هيتنشر كموقع (متسيبوش)
│   ├── index.html
│   ├── favicon.svg
│   ├── assets/
│   │   ├── style.css
│   │   └── app.js
│   └── data/
│       ├── seat/      ← ٩٧١ ملف، البحث برقم الجلوس
│       ├── name/      ← ١٢٥٨ ملف، البحث بالاسم
│       ├── trie.json  ← فهرس صغير بيوجّه البحث بالاسم للملف الصح
│       └── meta.json  ← إحصائيات عامة (العدد الكلي، أقصى مجموع...)
├── build_data.py      ← سكريبت إعادة بناء البيانات (مش بينتشر مع الموقع)
└── README.md          ← الملف ده
```

**البيانات دي عامة وموجودة أصلًا في نتيجة الوزارة الرسمية** — الموقع
ده مجرد وسيلة عرض أسرع وأسهل، مش مصدر رسمي، وده موضّح في أسفل الصفحة.

## إزاي البحث شغال من غير سيرفر؟

بدل ما الموقع يحمّل الـ٩١٩ ألف نتيجة مرة واحدة (حاجة تقيلة جدًا على
الموبايل)، البيانات مقسّمة لملفات صغيرة:

- **رقم الجلوس**: كل ١٠٠٠ رقم متتالي في ملف واحد صغير (~٨٠ كيلوبايت).
  لما حد يدور برقم جلوسه، الموقع بيحسب اسم الملف مباشرة من الرقم
  ويجيبه — نتيجة فورية.
- **الاسم**: شجرة بادئات (trie) بتتفرع تلقائي كل ما اسم يبقى شائع.
  البحث عن اسم نادر بيوديك لملف صغير جدًا، والبحث عن اسم شائع زي
  "محمد" بيوديك لعدة ملفات — لو كتر أوي، الموقع بيطلب منك تكتب اسم
  أطول بدل ما يحمّل كل حاجة.
