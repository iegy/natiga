# موقع الاستعلام عن نتيجة الثانوية العامة

موقع بسيط (HTML/CSS/JS من غير أي سيرفر) للاستعلام عن نتيجة الثانوية
العامة برقم الجلوس أو بالاسم. مبني عشان يتنشر مجانًا على GitHub Pages.

## المحتويات

```
repo/
├── docs/              ← ده اللي هيتنشر كموقع (متسيبوش)
│   ├── index.html
│   ├── favicon.svg
│   ├── assets/
│   │   ├── style.css
│   │   └── app.js
│   └── data/
│       ├── seat/      ← ٩٧١ ملف، البحث برقم الجلوس
│       ├── name/      ← ١٢٥٨ ملف، البحث بالاسم
│       ├── trie.json  ← فهرس صغير بيوجّه البحث بالاسم للملف الصح
│       └── meta.json  ← إحصائيات عامة (العدد الكلي، أقصى مجموع...)
├── build_data.py      ← سكريبت إعادة بناء البيانات (مش بينتشر مع الموقع)
└── README.md          ← الملف ده
```

**البيانات دي عامة وموجودة أصلًا في نتيجة الوزارة الرسمية** — الموقع
ده مجرد وسيلة عرض أسرع وأسهل، مش مصدر رسمي، وده موضّح في أسفل الصفحة.

## إزاي البحث شغال من غير سيرفر؟

بدل ما الموقع يحمّل الـ٩١٩ ألف نتيجة مرة واحدة (حاجة تقيلة جدًا على
الموبايل)، البيانات مقسّمة لملفات صغيرة:

- **رقم الجلوس**: كل ١٠٠٠ رقم متتالي في ملف واحد صغير (~٨٠ كيلوبايت).
  لما حد يدور برقم جلوسه، الموقع بيحسب اسم الملف مباشرة من الرقم
  ويجيبه — نتيجة فورية.
- **الاسم**: شجرة بادئات (trie) بتتفرع تلقائي كل ما اسم يبقى شائع.
  البحث عن اسم نادر بيوديك لملف صغير جدًا، والبحث عن اسم شائع زي
  "محمد" بيوديك لعدة ملفات — لو كتر أوي، الموقع بيطلب منك تكتب اسم
  أطول بدل ما يحمّل كل حاجة.

## خطوات النشر على GitHub Pages

### ١. اعمل مستودع (repository) جديد
على github.com اعمل New Repository (public، من غير README أو
.gitignore — إحنا جايبينهم جاهزين).

### ٢. ارفع الملفات
عدد الملفات كبير (حوالي ٢٢٣٠ ملف)، فاستخدم git من التيرمينال أو
GitHub Desktop، مش رفع بالسحب والإفلات من المتصفح (ده بيقف عند ~١٠٠
ملف). من جوه مجلد `repo/`:

```bash
git init
git add .
git commit -m "أول نسخة من موقع النتيجة"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO-NAME.git
git push -u origin main
```

استبدل `USERNAME` و`REPO-NAME` باسم حسابك واسم المستودع. الرفع ممكن
ياخد كام دقيقة لكتر عدد الملفات، ده طبيعي.

### ٣. فعّل GitHub Pages
في المستودع على GitHub: **Settings → Pages**
- **Source**: Deploy from a branch
- **Branch**: `main` واختار المجلد `/docs`
- Save

هياخد GitHub دقيقة أو اتنين لحد ما الموقع يفضح على رابط زي:
`https://USERNAME.github.io/REPO-NAME/`

## اختبار محلي قبل النشر (اختياري)

فتح `index.html` مباشرة من الملفات مش هيشتغل (المتصفح بيمنع
`fetch()` لملفات محلية لأسباب أمان). شغّل سيرفر بسيط بدل كدة:

```bash
cd docs
python3 -m http.server 8000
```

وافتح `http://localhost:8000` في المتصفح.

## لو نزلت نتيجة الدور الثاني بعدين

شغّل السكريبت تاني على ملف الإكسل الجديد، وهو هيمسح البيانات القديمة
جوه `docs/data` ويحط الجديدة مكانها تلقائي:

```bash
python3 build_data.py path/to/نتيجة_الدور_الثاني.xlsx
```

بعد كدة `git add .` و`git commit` و`git push` تاني عشان التحديث ينزل
على الموقع المنشور.

**ملحوظة:** لو ظهرت حالة جديدة في عمود الحالة (غير الأربعة الموجودة
دلوقتي) السكريبت هيوقف بخطأ واضح يقولك تضيفها — عشان كدة بيبقى مضمون
إنه مش هيسيب أي حالة من غير ما تتعرض صح على الموقع.

## تخصيص الشكل

الألوان والخطوط في `docs/assets/style.css` (متغيرات CSS في أول
الملف، تحت `:root`). منطق البحث في `docs/assets/app.js`.
